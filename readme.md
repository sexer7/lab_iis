# ЛР1. Настройка окружения и разведочный анализ данных

## Описание проекта

В проекте выполнен разведочный анализ датасета по продаже автомобилей. Цель работы - изучить структуру данных, проверить качество признаков, выполнить базовую очистку и подготовить очищенный датасет для следующих лабораторных работ, где будет строиться модель для предсказания цены продажи автомобиля.

Целевая переменная: `Selling_Price`.

## Запуск

Команды ниже актуальны для Windows PowerShell и текущего состояния ЛР1.

### 1. Клонирование репозитория

```powershell
git clone https://github.com/sexer7/lab_iis.git
cd lab_iis
```

### 2. Создание и активация виртуального окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Подключение окружения как Jupyter kernel

```powershell
python -m ipykernel install --user --name lab_iis --display-name "lab_iis (.venv)"
```

### 5. Продолжение работы с проектом

1. Откройте проект в VS Code.
2. Откройте блокнот `eda/eda.ipynb`.
3. Выберите kernel `lab_iis (.venv)`.
4. Запускайте ячейки блокнота.

Если репозиторий уже склонирован, то для повторного запуска обычно достаточно:

```powershell
cd lab_iis
.\.venv\Scripts\Activate.ps1
```

## Структура проекта

- `data/car_data.csv` - исходный датасет.
- `data/car_data_cleaned.csv` - очищенный датасет после EDA.
- `data/car_data_cleaned.pkl` - очищенный датасет в формате pickle с сохранением типов данных.
- `eda/eda.ipynb` - блокнот с разведочным анализом данных.
- `eda/selling_price_hist_interactive.html` - интерактивный график распределения цены продажи.
- `eda/present_vs_selling_price.png` - график зависимости цены продажи от текущей цены автомобиля.
- `eda/price_by_fuel_type.png` - анализ цены продажи по типу топлива.
- `eda/price_by_transmission.png` - анализ цены продажи по типу трансмиссии.
- `eda/top_car_models.png` - топ самых часто встречающихся моделей автомобилей.
- `eda/price_by_owner.png` - анализ средней цены продажи по количеству владельцев.
- `requirements.txt` - список библиотек, необходимых для запуска проекта.

## Результаты и выводы EDA

### Загрузка данных и знакомство с ними

- Исходный датасет содержит `301` запись и `9` признаков.
- Числовые признаки: `Year`, `Selling_Price`, `Present_Price`, `Driven_kms`, `Owner`.
- Категориальные признаки после корректировки типов: `Car_Name`, `Fuel_Type`, `Selling_type`, `Transmission`, `Owner`.
- Целевая переменная: `Selling_Price`.
- В датасете представлены автомобили `2003-2018` годов выпуска.
- В исходном датасете средняя цена продажи составляет `4.66`, медианная `3.60`, диапазон значений - от `0.10` до `35.00`.

### Очистка данных

На этапе очистки данных были выполнены следующие действия:

- Удалено `2` полных дубликата.
- Проверены диапазоны значений для `Year`, `Driven_kms` и `Selling_Price`.
- Проверено наличие пропусков: пропущенных значений в итоговом датасете нет.
- Признак `Owner` приведен к категориальному типу для более корректной дальнейшей обработки.

Новые признаки на данном этапе не создавались.

### Анализ признаков для модели

- Распределение `Selling_Price` имеет правостороннюю асимметрию: большинство автомобилей сосредоточено в нижнем ценовом диапазоне, при этом присутствуют дорогие выбросы.
- Наиболее сильная связь с целевой переменной наблюдается у признака `Present_Price` (`corr = 0.876`). Это означает, что текущая цена автомобиля является главным индикатором цены продажи.
- Признак `Year` положительно связан с `Selling_Price` (`corr = 0.234`): более новые автомобили в среднем продаются дороже.
- Признак `Driven_kms` почти не показывает линейной связи с ценой (`corr = 0.029`), но может быть полезен в комбинации с другими признаками.
- В очищенном датасете автомобили с дизельным топливом в среднем стоят дороже бензиновых. Для CNG наблюдений слишком мало, чтобы делать уверенный вывод.
- Автомобили с автоматической коробкой передач в среднем дороже автомобилей с механической коробкой.
- Продажи через дилера в среднем заметно дороже, чем продажи от частных лиц.
- Большая часть автомобилей имеет `0` предыдущих владельцев. Для групп с `1` и особенно `3` владельцами наблюдений мало, поэтому выводы по ним стоит интерпретировать осторожно.
- Наиболее часто в датасете встречаются модели `city`, `corolla altis`, `verna`, `fortuner`, `brio`.
